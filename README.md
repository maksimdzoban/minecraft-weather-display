# ❄️ Minecraft Weather Display (WebDisplays Mod)

Веб-інтерфейс моніторингу та прогнозу суворої погоди (-50°C ... -70°C) для Minecraft-серверів з підтримкою мода **WebDisplays**.

## 🚀 Як використовувати у грі:
1. Скопіюйте посилання на сайт: `https://maksimdzoban.github.io/minecraft-weather-display/`
2. У грі Minecraft побудуйте екран з блоків **Screen** (мод WebDisplays).
3. Клацніть правою кнопкою миші з інструментом налаштування екрану та вставте це посилання.
